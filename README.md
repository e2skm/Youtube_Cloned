# YouTube UI Clone

A static front-end clone of YouTube's interface built with HTML and CSS for practice purposes.

## 🚀 Features

- Responsive design mimicking YouTube's layout
- Modern CSS grid and flexbox implementation
- YouTube-style navigation bar and sidebar
- Video grid layout with thumbnails
- Clean, semantic HTML structure

## 🛠️ Technologies Used

- HTML5
- CSS3 (Flexbox, Grid)
- Responsive Design Principles

## 📁 Project Structure
youtube-clone/
├── index.html
├── styles/
│ └── style.css
├── images/
│ └── (thumbnail assets)
└── README.md

## 🎯 Purpose

This project was created to practice:
- Advanced CSS layout techniques
- Responsive web design
- UI/UX implementation skills
- HTML5 semantic structure

## ⚠️ Note

This is a **static front-end clone** only. It includes:
- ✅ Visual design replication
- ✅ Responsive layout
- ❌ No backend functionality
- ❌ No video playback
- ❌ No dynamic content
